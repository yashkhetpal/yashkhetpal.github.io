# Yash Khetpal — Portfolio

> Personal portfolio website. Live at: **https://yashkhetpal.github.io**

Hand-coded with HTML, CSS & JavaScript. Deployed via GitHub Pages.

## 📁 Structure

```
yash-khetpal.github.io/
├── index.html      # Main page (all sections)
├── style.css       # All styling (dark theme, teal accent)
├── script.js       # Scroll animations, progress bars
├── README.md       # You're reading this
└── assets/
    └── profile.jpeg
```

## 🛠️ Tech

- **HTML5** — semantic markup
- **CSS3** — Flexbox, Grid, custom properties, animations
- **JavaScript (vanilla)** — Intersection Observer, smooth scroll
- **Google Fonts** — Syne (display), Manrope (body), JetBrains Mono (mono)

## 🚀 Local Preview

Just open `index.html` in any browser. No build step, no dependencies.

For live reload, run:
```bash
# any of these work
python3 -m http.server 8000
# or
npx serve .
```

Then visit `http://localhost:8000`.

## 🌐 Deploying to GitHub Pages

1. Push this folder to a repo named **`yashkhetpal.github.io`** (must match your GitHub username exactly)
2. Go to **Settings → Pages**
3. Source: **Deploy from a branch**, Branch: **main**, Folder: **/ (root)**
4. Save and wait 1–2 minutes
5. Site goes live at `https://yashkhetpal.github.io`
